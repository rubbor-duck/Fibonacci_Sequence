# Overview

I am trying to expand my horizons and become more well rounded in my technical knowledge. I want to be able to not only write in more languages, but to be able to understand the challenges of other languages so I can become more understanding toward other engineers. 
I am doing this by learning Rust and writing a program in Rust.

The program that I wrote is a Fibonacci Sequence Calculator and a Factorial Calculator. It will calculate and display the fibonacci sequnce up to the specificed value the user chooses.
It will also calculate the factorial of a number up to a given value.

My purpose in writing this software is not only to learn a new language, but learn new coding techniques that other languages use that would be beneficial for me to use.
Learning Rust will also allow me to effectively talk to and collaborate with software engineers who write Rust.
